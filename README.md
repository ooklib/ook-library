# UFO Research LLM Wiki

Let's make a knowledge graph of the UFO Legacy programs and many other related mysteries.

Use LLMs to extract entities and relationships from public analyses, such as transcripts
of credible YouTubers, etc. and build a wiki using the Andrej Karpathy's
[LLM wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) mechanism.
Best viewed in Obsidian.
