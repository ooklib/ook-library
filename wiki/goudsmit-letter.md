A CIA-released letter by [[samuel-goudsmit]] (Coulthart/Cruickshank say "Goldsmith") responding to a 20 December 1957 communication about declassifying the "flying object committee's" conclusions. The cover of the released 154-page file carries an archivist's sticky note "CIA SI 28-55 UFOs"; the MJ-12 "first annual report" document carries the same designation. [[geoffrey-cruickshank]] and [[jed-davis]] argue the match shows the document's author had knowledge of a real CIA UFO file number.

## Claims

- Cruickshank: "CIA/SI 28-55" is the CIA scientific intelligence report nomenclature, adopted only in 1951 (1949-50 reports lack it), declassified only in 2000. *([rc/mj12](<../raw/rc/NewsNation - 2026-04-14 - A secret history - Inside shadow intelligence, the MJ-12 documents  Reality Check.md>) 59:44-1:00:50)*
- Text as read out: Goudsmit does not remember [[lloyd-berkner]] on "our committee" but remembers an Ohio State astronomer he thinks was Hynek. The panel is the [[robertson-panel-1953]] (14-17 January 1953); Hynek was officially not a member. The addressee's name stayed redacted until 2 April 2026, release date 2 April 2001. *([rc/mj12](<../raw/rc/NewsNation - 2026-04-14 - A secret history - Inside shadow intelligence, the MJ-12 documents  Reality Check.md>) 1:01:17-1:03:18)*
- The sticky note was reportedly added by the archivist and the file released six years after; Coulthart: a hoaxer using a real CIA UFO-file code "doesn't make any sense ... unless the document's real"; Cruickshank: "impossible ... these are real". Both note this is a 1980s-leaked document naming a file only declassified 2001. *([rc/mj12](<../raw/rc/NewsNation - 2026-04-14 - A secret history - Inside shadow intelligence, the MJ-12 documents  Reality Check.md>) 1:03:18-1:05:19)*
- Cruickshank then tells the Goudsmit/Alsos/Marconi/Fermi story (see [[samuel-goudsmit]]).
